
# Sistema de Monitoramento de Reservatório de Água

## Descrição
Este projeto simula o monitoramento do nível de água de um reservatório usando Python e a biblioteca Colorama.

## Tecnologias utilizadas
- Python
- Colorama

## Níveis do reservatório
- Nível 1: Muito baixo (crítico) - Vermelho
- Nível 2: Baixo - Amarelo
- Nível 3: Médio - Verde
- Nível 4: Alto - Ciano
- Nível 5: Muito alto (alerta) - Azul

## Como executar
1. Instale o Python.
2. Instale a biblioteca com o comando: pip install colorama
3. Execute o arquivo reservatorio.py.

## Objetivo
Praticar listas, funções, estruturas condicionais e bibliotecas em Python.
